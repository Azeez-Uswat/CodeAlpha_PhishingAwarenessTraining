# CodeAlpha Cybersecurity Internship - Task 2: Phishing Awareness Training

## Project Overview
PhishShield is an interactive security awareness web module built to educate users on recognizing, avoiding, and mitigating phishing and social engineering attacks.

## Key Features
- **Interactive Phishing Anatomy:** Breakdown of lookalike domains, spoofed headers, and urgent calls-to-action.
- **Social Engineering Tactics:** Analysis of psychological triggers (Urgency, Authority, Fear, Social Proof).
- **Real-World Case Studies:** Breakdowns of multi-million dollar BEC and wire fraud incidents.
- **Interactive Knowledge Check:** Dynamic evaluation quiz with real-time feedback.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (zero external dependencies).
